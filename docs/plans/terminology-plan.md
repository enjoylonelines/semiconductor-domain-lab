# Terminology Glossary 계획·초기 읽기 표

상태: 학습용 초안. 독자가 이 용어를 습득했다는 기록이 아니다. [주 계획서](domain-learning-plan-2026-09-23.md)와 [출처 장부](../references/source-register-2026-09-23.md)를 함께 읽는다.

## 표기·검증 방식

영문 원어 / 약어 / 한국어 표기·실무 호칭 / 발음 / 한 줄 의미 / 업무 예문 / 관련 단계 / 정의 근거 / 한국어 용례 근거 / 확인 상태를 유지한다.
아래는 간결하게 한국어 표기와 읽기를 한 열로 합친 초기 표다. 정식 학습 노트에서는 이 필드를 분리해도 된다.

- 단계: D=도메인 지도, E=EDA 흐름, P=PHY·측정 개념, S=SW 업무, H=작은 실험.
- ★=우선 자기 말로 설명할 핵심 20개. 나머지는 조회용이며 전부 암기할 필요 없다.
- 예문은 모두 **S: 작성한 업무 상황 예시**다. 회사 내부 발언이나 실제 수행한 작업의 인용이 아니다.
- 출처 열의 앞은 정의·관련성 근거, 괄호 안 K/C는 한국어 문서 용례 근거다. “독음 U”는 한글 읽기의 현업 통용성이 별도로 확인되지 않았다는 뜻이다.
- 별도 확인 표시가 없으면 한글 읽기는 **S: 독자를 위한 읽기 가이드**다. 영어 약어를 한국어로 적었다는 이유로 실제 현업 발음 빈도를 입증했다고 보지 않는다.
- EDA job, backend 등의 업무 의미는 단계에 따라 달라진다. 특히 반도체 backend(물리 설계)와 SW backend(서버)를 구분한다.
- SW 기본 용어의 행은 계획 이해를 위한 S 정의다. J2/J3는 사용 관련성만 확인하는 출처이며, 전송 보장이나 데이터베이스 동작 의미를 증명하는 기술 문서가 아니다. 후속 학습에서 세부 동작이 필요하면 해당 제품의 공식 문서를 대조한다.
